Política de Privacidade

Última atualização: 8 de novembro de 2026

1. Sobre este aplicativo

O ofertasdalala é uma ferramenta de automação que ajuda criadores de conteúdo a preparar e enviar vídeos promocionais de produtos para o TikTok como rascunhos. O criador revisa e publica o conteúdo manualmente no aplicativo do TikTok.

Esta política explica quais dados o aplicativo acessa, como usa esses dados, por quanto tempo os mantém e como o usuário pode solicitar a exclusão.

2. Dados que acessamos

Quando o usuário autoriza o aplicativo, podemos acessar:

  • Identificador público da conta TikTok (open_id).
  • Nome de exibição e avatar públicos.
  • Permissão para enviar vídeos como rascunho para a conta autorizada.
  • Informações técnicas do envio, como data, status e mensagens de erro.

Não acessamos senha, mensagens privadas, lista de seguidores ou dados de pagamento do TikTok.

3. Como usamos os dados

  • Autenticar a conta TikTok autorizada.
  • Enviar o vídeo escolhido para a caixa de entrada de rascunhos do TikTok.
  • Exibir o status do envio e permitir nova tentativa em caso de erro.
  • Registrar falhas técnicas para corrigir o serviço.

Não usamos os dados para anúncios, perfilamento ou venda a terceiros.

4. Compartilhamento

Os dados são compartilhados apenas com o TikTok, por meio da API oficial, para realizar o envio solicitado pelo próprio usuário. Também usamos provedores de hospedagem e armazenamento necessários para operar o serviço.

Não vendemos dados pessoais.

5. Armazenamento e segurança

Tokens de acesso são armazenados de forma cifrada. O acesso é restrito às pessoas responsáveis pela operação do aplicativo. Vídeos e textos ficam armazenados apenas pelo tempo necessário para a preparação e o envio do conteúdo.

Nenhum sistema é totalmente imune a falhas. Por isso, recomendamos que o usuário revogue o acesso do aplicativo no TikTok quando não quiser mais usá-lo.

6. Retenção

Vídeos enviados para rascunho podem ser removidos do nosso armazenamento após o envio ao TikTok. Registros técnicos podem ser mantidos por até 90 dias para segurança e diagnóstico.

Tokens podem ser mantidos enquanto o usuário mantiver a conta conectada.

7. Direitos do usuário

O usuário pode solicitar:

  • Acesso aos dados armazenados.
  • Correção de dados incorretos.
  • Exclusão dos dados.
  • Revogação do acesso do aplicativo.

Para revogar o acesso, use as configurações de aplicativos conectados no TikTok. Para solicitar exclusão, envie um e-mail para contato@ofertasdalala.com.br.

8. Exclusão de dados

Ao receber uma solicitação de exclusão, removemos os tokens, os vídeos e os registros técnicos associados à conta, salvo quando a lei exigir retenção. A solicitação é respondida em até 30 dias.

9. Cookies e tecnologias similares

O aplicativo pode usar cookies de sessão para autenticação e segurança. Não usamos cookies de publicidade.

10. Menores de idade

O aplicativo não é direcionado a menores de 18 anos. Não coletamos intencionalmente dados de menores.

11. Alterações

Esta política pode ser atualizada. A data no topo indica a versão vigente. Mudanças relevantes serão comunicadas no site ou por e-mail.
